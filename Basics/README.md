```cpp
  #include<iostream>
  using namespace std;

  int main(){
     // code-----
     return 0;
  }
```

## libraries 
→ provides with built in functions and tools ex - 
- `#include<iostream>` -> for cout & cin
- `#include<math.h>` -> for math operations
- `#include<bits/stdc++.h>` -> includes allmost all standard libraries of c++ -> used in compitative programming

## namespace
- use using namespace std; or std:: in front of every function
- by using namespace std; improves visibility & readibility of code

## Input & Output
- `cout<<` -> for output
- `cin>>` -> for input

## new line
- `\n` (new line character) -> fast
- `std::endl` -> slower & along with new line flushes out the output buffer -> time consuming
- `::` -> scope resolution operator -> use right function from the scope of left
